### 👨‍💻 About Me

I am a **Full-Stack AI Engineer** and **Frontend Mentor** based in Qarshi, Uzbekistan. I specialize in engineering production-ready web architectures with **Next.js (App Router)**, deterministic AI agents utilizing **Gemini 2.0 Flash Tool Calling**, and relational database integrations with **Supabase / Prisma**.

- 🔭 **Currently Building:** [OmniSupport AI](https://github.com/Temurprogram77/OmniSupport-AI) — Autonomous logistics & order support agent with live database mutations.
- 💼 **Mentorship:** Mentoring aspiring frontend developers in React, TypeScript, and modern ecosystem standards at **Sfera IT Academy**.
- 🏢 **Enterprise Work:** Co-architected **Sfera Nazorat CRM**, an internal enterprise ERP platform that completely digitized student tracking and financial workflows.
- ⚡ **Core Philosophy:** Clean code architecture, zero-hallucination agentic guardrails, and responsive, high-performance user interfaces.
